## BLOQUE 2 (43') — M31: "hay" = THERE IS / THERE ARE

- **Puente desde Cl 26 (4'):** escribes *"Do you have any pizza? — I have some pizza."* (M17). Una sola linea: *"You know SOME and ANY. Today, 'hay': THERE IS, THERE ARE. Never 'have' for 'hay'."*
- **Tablero verbatim (M31, Guia 1, p.345) (12'):**

```
1. "Hay": singular o incontable = THERE IS. Plural = THERE ARE.
   "any / some" se tratan exactamente como ya sabes.

  FORMA          SINGULAR            INCONTABLE              MULTIPLE
  Afirmativo     There is a car.     There is some salt.     There are some cars.
  Negativo       There isn't a car.  There isn't any salt.   There aren't any cars.
  Interrogativo  Is there a car?     Is there any salt?      Are there any cars?

2. Respuesta corta: Yes, there is. / No, there isn't.
                    Yes, there are. / No, there aren't.
```

  Vocabulario (p.344): *salt · sugar · butter · a movie · a player · a cookie* + la comida de Cl 36 (*bread · cheese · milk · eggs · juice · meat*). Coro 3x por columna, siempre en trio afirmativa → negativa → pregunta, marcando con la mano ARRIBA la pregunta (*"Is THERE..."* — el verbo salta, como en Cl 32). El error que vas a cazar: *"Have bread?"* / *"There have..."* (el "hay" espanol), *"There are a car"*, *"There is any salt"*.
- **Historia interactiva (17'):** TU narras "la cocina del restaurante nuevo, una hora antes de abrir: el chef abre la nevera". Narras 2-3 frases (*"The restaurant opens at 7:00. The chef opens the fridge. Is there any milk? No, there isn't any milk! Are there any eggs? Yes, there are some eggs... but there are only two.
