# MAPA DE COMPETENCIA Y ARQUITECTURA DEL PRODUCTO RECURRENTE
### Para Carlos · 03/09/2026 · Insumos: propuesta RISE, propuesta + demo Core financiero (30 min)

---

## 1. EL MAPA (3 jugadores, 3 negocios distintos)

| | RISE | Core financiero | Carlos |
|---|---|---|---|
| **Qué vende** | Dashboard técnico con IA, a la medida | Suite de reportes financieros recurrente | Criterio: qué está mal en tus números y qué decidir |
| **Precio** | US$500-1.000 pago único (+extras) | $605k-$1.475k COP/mes por tamaño + setup $1.49M | Radiografía US$1.200 único + Tablero US$300/mes |
| **Comprador real** | Quien ya sabe qué métricas quiere | El que SABE de finanzas (CFO, VP financiero, empresa grande con data impecable e históricos) | El gerente que sabe de su negocio pero NO de finanzas |
| **Dato sucio** | Problema del cliente ("entre más ordenado tu documento, mejor") | Problema del cliente ("presupuesto preparado por la empresa") | ES el producto (la radiografía lo corrige) |
| **Recurrencia** | Ninguna | Mensual por planes | Mensual |

**Hallazgo del demo (30 min):** Core es perfecto para una multinacional con información organizada al detalle. Para un empresario mediano/pequeño esa información es PESADA — no la va a analizar. Core le vende al financiero; Carlos le sirve al empresario. **No competimos por el mismo comprador.** El riesgo solo aparecería si Core saca una versión simplificada para pymes (hoy no existe).

## 2. QUÉ COPIARLE A CORE (estructura comercial, no contenido)

1. **Precio por tamaño del cliente** (rango de ventas mensuales), no por costo del servicio.
2. **Setup separado de la mensualidad** (implementación única + plan recurrente).
3. **Horas humanas tarifadas dentro del plan** (X horas de comité/mes incluidas; hora adicional con precio fijo). Protege el tiempo de Carlos = el modelo escala.
4. **Los dos framings de venta:**
   - "El servicio cuesta entre el 0,1% y el 0,2% de tus ventas — y si tus ventas crecen, el % baja."
   - "El plan más completo cuesta menos que un auxiliar administrativo."
5. Oferta con vigencia (15 días) · empresa adicional del grupo se cobra aparte.

## 3. QUÉ HACER AL REVÉS DE CORE (aquí vive la diferencia)

| Core (para financieros) | Carlos (para empresarios) |
|---|---|
| 8 grupos de reportes, drill-down por cuenta | **8-10 indicadores máximo, en semáforo, una página** |
| El cliente interpreta | **Lectura mensual en lenguaje de gerente: "esto subió, esto está mal, esta semana decide esto"** |
| Asume contabilidad impecable | **Primero radiografía: verificar que las cifras sean verdad** |
| Actualización diaria como premium | Mensual basta — el empresario decide por mes, no por minuto |
| Históricos de 4 años | Los 3-6 meses que muestran la tendencia |

**Frase de posicionamiento:** "Ellos te muestran cifras. Yo primero verifico que tus cifras sean verdad — y después te digo qué decidir."

## 4. ESQUELETO DEL PRODUCTO RECURRENTE (borrador para discutir)

- **Puerta de entrada (setup):** Radiografía — corrige la clasificación, define los 8-10 indicadores del negocio, arma la plantilla de datos que el contador llena en 20-30 min/mes. (Equivale al setup $1.49M de Core; Carlos ya la cobra US$1.200.)
- **Plan recurrente (el gimnasio):** tablero actualizado + lectura mensual de Carlos (comentario de 15-20 min: semáforos + 2-3 decisiones). Compromisos de 3/6/12 meses con mejor tarifa a mayor plazo.
- **Escalera de planes (2 o 3 máximo, no 4):** p. ej. BÁSICO tablero + lectura escrita · COMPLETO tablero + lectura + 1 hora de comité/mes · hora adicional tarifada.
- **Tecnología:** se compra o se arma por plantilla de industria (proveedores tipo RISE la venden a US$500 — es costo, no producto).
- **Precios:** anclar por tamaño de empresa usando la lógica Core; el tablero actual de US$300/mes queda como referencia del plan medio para cliente USA. Definir tabla COP para cliente Colombia.

## 5. QUÉ NO HACER

- No competir con RISE en precio de dashboard (carrera al fondo, y Carlos no es programador).
- No copiar el contenido de Core (abruma al empresario — el demo lo confirmó).
- No vender el dashboard sin la lectura (dashboard huérfano = churn en 2 meses).
- No aceptar clientes con datos vueltos nada directo al plan mensual: primero radiografía, siempre.
- Cifras de clientes reales jamás en material público (solo "cifras ilustrativas").
